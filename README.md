# PDRA — Beta Feedback

This is the **public feedback tracker** for PDRA, an AI assistant add-in for
Autodesk Revit (2025/2026). The source code is private; this repo exists so
beta testers can report bugs and request features without needing access to
the code.

## Tester guide

New tester? Start with **[TESTING.md](TESTING.md)** — install, connecting
Claude Desktop / Codex, first prompts, privacy, troubleshooting.

## Report a bug

[**Open a bug report →**](../../issues/new?template=bug_report.md)

Please always include:

- **PDRA version** — shown in the title of the PDRA Chat panel in Revit
  (e.g. `PDRA Chat v1.1.1`)
- **Revit version** — 2025 or 2026, plus update number (Help → About)
- **AI client** — Claude Desktop / Codex / in-Revit chat panel
- What you asked or clicked, what you expected, what happened
- A screenshot of any error dialog

## Request a feature / missing tool

Found something PDRA should be able to do but can't? Either open an issue
here, or — better — use the **Propose new tool…** button in PDRA's Tools
Browser inside Revit: it captures the request in exactly the format the
developer needs.

## Getting the installer

The installer is distributed directly to invited testers. If your build has
expired (beta builds stop ~60 days after release), ask for the latest
installer.
